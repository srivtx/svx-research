SVX Research — The Missing Software
================

The continuously operating research brain of the SVX system: track
reports (R1-R13), verification passes (R13a/b, V1-V3), the living gap
registry, and the immutable raw-evidence layer. Research pushes
findings here; products are built as separate repos in the family
([svx-evalgate](https://github.com/srivtx/svx-evalgate),
[svx-careops](https://github.com/srivtx/svx-careops),
[svx-parityrun](https://github.com/srivtx/svx-parityrun)) from
verified-open registry rows.

The whole story and operating protocol: [`AGENT-MISSION.md`](../AGENT-MISSION.md).
The only research-to-product handshake point: [`docs/gap-registry.md`](../docs/gap-registry.md).

Layout
------

- `track-reports/` — the analyses (R1-R13 track reports, R13a/R13b/V1/V2/V3 verification passes)
- `raw-search-results/` — immutable raw search evidence, one directory per agent run (never edited after save)
- Wave 1 (R1-R5): dev tooling, integration/data, missing links, badly-built categories, frontier gaps
- Wave 2 (R6-R13b): six never-searched verticals cleared; gaps #2-#5 re-verified; rows 13-14 found
- Wave 3 (V1-V3): row 13 + row 14 kill-passes (both OPEN → productized); registry follow-ups run
