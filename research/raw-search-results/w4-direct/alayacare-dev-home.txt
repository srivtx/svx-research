New Documentation Platform This is the new AlayaCare documentation platform. The old one is still available at https://alayacare.github.io/external-integration-docs/external-api-guide.html Overview AlayaCare provides external APIs that allow you to integrate with our platform and access data programmatically. Our APIs are RESTful and follow standard HTTP conventions. What You Can Do With our external APIs, you can: Manage Clients : Create, update, and retrieve client (patient) information Handle Employees : Manage employee data, skills, and availability Schedule Services : Create and manage visits, tasks, and care plans Access Clinical Data : Retrieve clinical information and forms Process Files : Upload and manage documents Handle Accounting : Access billing and financial data Manage Medications : Track medication information Getting Started Review Available APIs : Check out our API reference for detailed specifications Set Up Authentication : Learn about our authentication methods Choose Your Integration Method : Use our REST APIs for real-time data access Use Flat File Integration for batch data processing Support For technical support or questions about our APIs, please contact your AlayaCare representative or our technical support team.
